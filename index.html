Battery Charge Limit

Stop your travel router sitting at 100% on the charger. Cap it at 80% (or anything from 50–100%) to keep the battery healthy for longer.

50–100%adjustable limit
1 minto install
Built-in UIslider in the admin panel

USB & Power slider

Switch + slider under System → USB & Power.

Shown on the dashboard

Limit appears on Overview and next to the battery on the Internet page.

Survives reboots

Pauses charging at the limit, resumes 5% below it.

1 Open Plug-ins → Manage Sources

In the router admin panel go to Applications → Plug-ins and click Manage Sources (top right).

Click Manage Sources
Applications → Plug-ins

2 Add the source

Enter a name and this URL, click the +, then Apply.

Name
chargelimit
URL
https://jrelph.github.io/glinet-mudi7-e5800-charge-limit/feed
① Name
② URL
③ Click +
④ Apply

3 Install the plug-in

Back on Plug-ins, click Refresh, search for chargelimit and click install. Then hard-refresh your browser (Cmd/Ctrl + Shift + R).

Find the slider under System → USB & Power.

Prefer the command line?

echo 'src/gz chargelimit https://jrelph.github.io/glinet-mudi7-e5800-charge-limit/feed' >> /etc/opkg/customfeeds.conf
opkg update
opkg install gl-sdk4-ui-chargelimit

Or download the .ipk and run opkg install on it.

Uninstall

Click uninstall in Plug-ins (or opkg remove gl-sdk4-ui-chargelimit). Original UI files are restored and normal charging resumes.

Good to know: tested on GL-E5800 (Mudi 7), firmware 4.10.0. The stock charger daemon briefly re-enables charging, so the level can creep up a little over long periods on the charger. A firmware upgrade removes the UI patch — just reinstall the plug-in. Use at your own risk; this modifies system files.
